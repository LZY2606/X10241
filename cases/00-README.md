# 源组成室离线案例包：同位素端元、分馏假设与可行混合区间

本目录是**领域专用**的离线案例包，不是通用表格。每个 `case-*.json` 都保存一次样品/端元/
测量协方差/分馏版本/单位/先验的**原始记录**（raw token + 单位 + 坐标基准），并给出该次
反演期望的机器可读判定（`expect`）与来源链断言（`provenance`）。

## 叙事线（重放记录）

1. `case-01-baseline` — 初始版本：审阅者核对样品、三端元、测量协方差、分馏 v1、单位、先验。
2. `case-02-collinear` — 近共线端元：必须明确报可识别性不足，保留全部合法候选。
3. `case-03-outside` — 样品超出端元包络：可行域为空、报超界，不伪造单点答案。
4. `case-04-correlated` — 相关测量误差：非对角协方差必须按协方差传播。
5. `case-05-missing-dimension` — 缺失同位素维：原值留在原位附诊断，按剩余维度判定。
6. `case-06-fractionation-switch` — 分馏版本切换：从 v1 切到 v2，旧结论不被覆盖。
7. `case-07-multiple-regions` — 端元为高斯混合，产生两个互不连通的可行区，全部保留。
8. `case-08-infeasible-prior` — 不可行先验：先验与单纯形无交集，显式拒绝而非截断归一化。

随后案例脚本再执行：一次参数修订（分馏 v1→v2）、一次只影响局部依赖的源数据改动
（只改一个端元，只失效引用它的试验）和一次互相冲突的人工决定（乐观并发 409）。

## 单位与坐标基准

- 碳同位素：`‰ VPDB`；氮同位素：`‰ AIR`。
- 导入时保留 `rawToken`；派生层才规范化。无法转换的值留在原位并写 `diagnostics`，
  绝不为了画图丢弃。

## 模型

可行比例在约束单纯形 `{p_i >= 0, sum p_i = 1}` 上网格采样（不做截断后归一化）：

  y ~ N( Σ_i p_i (μ_{i,k_i} + f),  S_e + Σ_i p_i S_{i,k_i} )

端元允许是高斯混合（多个 mode），此时可行域是凸集的并，可能真正互不连通。
